# Changelog

## 0.1.0 (unreleased)

* Envelope 1.0: record ids, kinds, actors, sources, relations, visibility,
  lifecycle, typed extensions.
* Append-only events with projection, diffs and timelines; corrections,
  retractions, supersession, redaction, annotations.
* Validation with size limits and untrusted-input rules.
* Repository with idempotency and optimistic concurrency.
* Memory and SQLite stores; graph queries and bounded traversal.
* Viewer-based visibility and identity disclosure.
* Bundle format 1.0 with canonical JSON hashing and verified import.
* Conformance fixtures, a boundary test, and a non-issue example consumer.
* Project tooling: GitHub Actions CI, cargo-deny policy, pre-commit hooks,
  pinned toolchain (MSRV 1.85), CONTRIBUTING and Code of Conduct.
